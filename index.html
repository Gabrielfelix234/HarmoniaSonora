SOBRE O PROJETO

Como funciona?

O Harmonia Sonora é uma plataforma interativa criada para apresentar diferentes artistas através de um painel de sons.

Escolha um dos três artistas disponíveis e explore suas músicas. Ao clicar nos botões, o som selecionado será reproduzido e a imagem relacionada ao artista será apresentada.

O projeto utiliza HTML, CSS e JavaScript para criar uma experiência visual e interativa.
